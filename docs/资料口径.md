# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

service_code为实际服务类，execution_id为真实执行；status=confirmed才计已核实服务，cancelled申请不自动删execution。包的slot是承诺单位，exclusive_group同组一次执行最多兑一项；不同执行可各兑剩余单位。替代仅按substitutions。价格按销售时各slot的relative_price×units作为全包固定分母；只确认部分执行时未分部分保留在包，不能对已执行项重新归一。退款给明示slot及units，只撤对应未使用权益；若触及已兑现，保留争议不倒删服务。cash为真实收退款，不等于收入形成。refund文档amount是实退事实，退款资格与金额差异单列。

## packages
销售包。

记录键：['package_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| package_id | string | 包 |
| person | string | 人 |
| sold_at | datetime | 销售 |
| price | number | 合同价 |

## slots
销售时承诺及权重。

记录键：['slot_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| slot_id | string | 权益 |
| package_id | string | 包 |
| service_code | string | 类 |
| units | number | 总单位 |
| relative_price | number | 相对价 |
| exclusive_group | string | 互斥组 |

## requests

记录键：['request_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| request_id | string | 申请 |
| person | string | 人 |
| service_code | string | 类 |

| 字段 | 类型 | 含义 |
| --- | --- | --- |

## refunds
后续可单独接收的权益撤回。

记录键：['refund_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| refund_id | string | 退 |
| slot_id | string | 权益 |
| units | number | 撤回单位 |
| amount | number | 实退元 |
| at | datetime | 时点 |

## cash
不因收入归属重新生成。

记录键：['cash_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| cash_id | string | 流水 |
| package_id | string | 包 |
| kind | string | receive或refund |
| amount | number | 正金额 |
| at | datetime | 时点 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

本包G1是P1的一次同类服务跨包互斥范围，F1/F2故意重复主张，未经核实不选先录者。refunds是事实源，cash中对应退款是现金证据，两表不可相加成两次退款；可用refund_id或明确package/at/amount匹配，无法唯一对应留待核。PK1总权重为1000，已兑现收入按合同价800乘固定全包比例，剩余仍留包。
